# SmartLights
SmartLights is a road simulation framwork made to emulate traffic lights.  
The projects end goal is to utilized the simulation to display a better light
timing program without need to implement it in a real situation.

Being able to simulate traffic patterns allows for discovery in more radical
light patterns without endagering or creating severe traffic build up.

To start the gui run from SmartLights.simulation import gui  
Intersections can be modified within the gui
